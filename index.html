2数据分层规范（L1 / L2 / L3）

对应 PRD 第四点。本次新增三项分层治理要求（元信息标记 / L3 有效期 / L2 阈值版本），保障跨周期口径一致。

层级定义示例字段加工方
L1 原始经营号直采，不做业务判断SKU 价格/销量/GMV、场次 GMV、投放消耗/ROI、支付用户数、新客数、老客数经营号
L2 衍生基于 L1 做规则化计算，参数可配置货盘结构分类、大场判定、新客率、复购率、复购间隔、智投占比经营号（参数 Skill 下发）
L3 补录机器拿不到的主观/文本/外部/历史数据产品线映射、背书文案、装修自查、同比历史、竞品数据、微信豆数据客户/销售填录

新增分层治理要求 新增

  • 字段级数据来源标记：每个字段附带来源标记（direct 直采 / backfill 补录 / missing 缺失），Skill 据此决定做完整诊断还是降级为定性描述，避免缺失被隐藏。
  • L3 数据有效期：同比历史、竞品、装修自查等 L3 数据附「采集时间戳 / 有效期」；超期时报告需标注「基于 X 月补录数据，可能已过期」。
  • L2 阈值版本管理：大场判定倍数、货盘价格带等阈值携带「行业维度 + 生效时间区间 + 版本号」，避免跨月复盘口径不可比。
  • 同比硬约束：经营号仅有客户授权后数据 → 环比可直采；同比需 L3 补录去年同期数据。
